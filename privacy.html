Política de privacidad de MC Voice

Última actualización: 11 de noviembre de 2026. Contacto: johandemelisagutieres@gmail.com.

1. Resumen

MC Voice es una aplicación Android para chat de voz, grabación de pantalla y transmisión de partidas. Esta política explica qué datos utiliza la aplicación y cómo se manejan.

2. Datos de Google/YouTube

Si conectas YouTube, la aplicación solicita el permiso https://www.googleapis.com/auth/youtube mediante el flujo OAuth de código de dispositivo. El permiso permite a MC Voice consultar el nombre de tu canal, crear y administrar los directos que tú inicias desde la aplicación, configurar título, descripción, privacidad y miniatura, obtener la clave de transmisión necesaria para emitir, y leer el chat en vivo de tu propio directo.

3. Uso de los datos de Google

Los datos se usan para proporcionar las funciones de YouTube que el usuario activa dentro de MC Voice. La aplicación se comunica directamente con las API de Google/YouTube. El proyecto MC Voice no opera un servidor que reciba o almacene los datos de tu cuenta de Google. Los datos de Google no se venden ni se usan para publicidad o entrenamiento de modelos de inteligencia artificial. MC Voice cumplirá la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

4. Almacenamiento y eliminación

Los tokens OAuth y el nombre del canal se guardan en el almacenamiento privado de la aplicación en tu dispositivo. Los mensajes del chat se mantienen en memoria mientras se ejecuta la aplicación. Puedes retirar el permiso desde la opción para desconectar YouTube en MC Voice o desde la configuración de permisos de tu cuenta de Google. Desinstalar la aplicación elimina los datos locales guardados por ella.

5. Twitch y TikTok

Si conectas Twitch, MC Voice utiliza los permisos necesarios para obtener la clave de transmisión y actualizar el título. Los tokens se guardan en el dispositivo y puedes retirar el acceso desde las conexiones de Twitch. MC Voice no inicia sesión en TikTok ni utiliza la API de TikTok: si introduces una dirección de servidor y una clave que TikTok te haya proporcionado, la aplicación las utiliza para enviar la transmisión al destino que elegiste.

6. Salas de voz y transmisión

El audio de las salas se transmite entre los dispositivos mediante WebRTC. El servicio público de señalización PeerJS ayuda a que los dispositivos se encuentren y puede procesar el código de sala y datos técnicos de conexión; el audio de la llamada se transmite entre los participantes. Tu apodo se muestra a las personas de tu sala. Cuando grabas o transmites, el video de pantalla y el audio que incluyas se envían a la plataforma de destino seleccionada.

7. Permisos del dispositivo y grabaciones

La aplicación puede solicitar acceso al micrófono, captura de pantalla, notificaciones, ejecución en segundo plano y superposición sobre otras aplicaciones para ofrecer voz, grabación, transmisión y controles flotantes. Las grabaciones se guardan en el dispositivo, en la carpeta Movies/MCVoice; el proyecto no las sube a un servidor propio.

8. Menores

MC Voice no está dirigida a menores de 13 años y no busca recopilar deliberadamente datos personales de menores de esa edad.

9. Cambios y contacto

Esta política puede actualizarse si cambian las funciones o el tratamiento de datos. Para consultas o solicitudes relacionadas con privacidad, escribe a johandemelisagutieres@gmail.com.

Privacy Policy (English)

Last updated: November 11, 2026. Contact: johandemelisagutieres@gmail.com.

MC Voice is an Android app for voice chat, screen recording and game streaming. If you connect YouTube, the app requests https://www.googleapis.com/auth/youtube through Google's OAuth device flow. It uses this access to identify your channel, create and manage broadcasts you start in the app, set broadcast metadata and thumbnails, obtain the stream key, and display the live chat of your own broadcast.

Google OAuth tokens and your channel name are stored in the app's private storage on your device. The app communicates directly with Google/YouTube APIs; the MC Voice project does not operate a server that receives or stores your Google account data. Google data is not sold or used for advertising or AI model training. Use of Google API data is subject to the Google API Services User Data Policy, including Limited Use.

You can revoke Google access in the app or at Google Account permissions. Twitch tokens are stored on your device and access can be removed at Twitch connections. MC Voice does not sign in to TikTok or use its API; user-provided server URLs and stream keys are used to send the stream to the selected destination.

Voice rooms use WebRTC for participant audio and PeerJS for signaling; the signaling service may process room codes and technical connection data. Screen video and selected audio are sent to the streaming platform you choose. Recordings are saved locally under Movies/MCVoice and are not uploaded to an MC Voice-operated server.

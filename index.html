MC Voice

MC Voice es una aplicación para Android dirigida a jugadores de Minecraft. Permite hablar por voz con amigos, grabar la pantalla y transmitir partidas a plataformas compatibles.

Funciones

  • Salas de voz para hablar con amigos mientras juegan.
  • Grabación de pantalla con audio del juego y de la conversación.
  • Conexión con YouTube para crear, iniciar y terminar directos desde la aplicación, configurar título, descripción, privacidad y miniatura, y mostrar el chat del directo.
  • Conexión con Twitch para funciones de transmisión compatibles.
  • Envío de una transmisión a TikTok mediante la dirección del servidor y la clave que proporciona el propio usuario; MC Voice no inicia sesión en TikTok ni usa su API.

Datos de Google y YouTube

Si eliges conectar YouTube, MC Voice solicita el permiso https://www.googleapis.com/auth/youtube para administrar los directos que tú inicias desde la aplicación y mostrar el chat de tu propio directo. Los tokens y el nombre del canal se guardan en el almacenamiento privado de la aplicación en tu dispositivo. La aplicación se comunica directamente con las API de Google/YouTube; el proyecto no opera un servidor que reciba esos datos.

MC Voice usa YouTube API Services. Al usar esas funciones también aceptas los Términos de servicio de YouTube y reconoces la Política de privacidad de Google. Puedes retirar el acceso en tu cuenta de Google.
